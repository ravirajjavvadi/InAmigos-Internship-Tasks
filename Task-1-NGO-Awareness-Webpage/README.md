# 🏁 TASK 01: RESONATING FOR CHANGE 🟢

### *Re-engineering the NGO Awareness Experience*

This task involved the creation of a high-fidelity, modern awareness landing page for the **InAmigos Foundation**. The goal was to move beyond static information and create a **visual journey** that resonates with donors and volunteers.

---

## 💎 CORE FEATURES
- **Visual Storytelling**: High-saturation imagery paired with youth-empowerment copy.
- **Semantic Precision**: Optimized HTML5 structure for SEO and accessibility.
- **Glassmorphic UI**: Modern CSS components including blurred cards and soft gradients.
- **Responsive Mastery**: Fluid layouts that adapt from ultra-wide 4K displays to mobile viewports.

---

## 📐 TECHNICAL BREAKDOWN
- **Structure**: Semantic `index.html`
- **Aesthetics**: `style.css` (Fluid Grid System, Custom Animations)
- **Interaction**: `script.js` (Smooth Scroll, Form Validation)

---

## 🚀 IMPACT STATEMENT
> "A website is the digital face of a mission. By engineering a high-fidelity awareness page, we provide the Foundation with a tool that converts passive visitors into active supporters."
