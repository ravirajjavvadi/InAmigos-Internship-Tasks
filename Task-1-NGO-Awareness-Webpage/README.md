# InAmigos NGO Awareness Webpage

A modern, high-fidelity NGO awareness webpage developed as part of the AI Web Development Internship Task. This project demonstrates a focus on premium UI/UX, smooth interactivity, and professional web standards.

## ✨ Features
- **Premium UI/UX**: Designed with a focus on modern aesthetics, including glassmorphism and mesh gradients.
- **Micro-Interactions**: Features magnetic buttons and smooth hover effects.
- **Scroll Animations**: Custom "Reveal on Scroll" implementation using the Intersection Observer API.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **Semantic HTML**: Built with SEO and accessibility best practices in mind.

## 🛠️ Technologies Used
- **HTML5**: Structured with semantic tags.
- **Vanilla CSS3**: Styled with CSS variables and advanced layout techniques (Flexbox/Grid).
- **JavaScript (ES6)**: Enhanced with modern APIs for animations and interactions.
- **Lucide Icons**: High-quality, scalable SVG icons.
- **Google Fonts**: 'Outfit' and 'Inter' for professional typography.

## 🚀 How to View
1. Navigate to the `Task-1-NGO-Awareness-Webpage` directory.
2. Open `index.html` in any modern web browser.
