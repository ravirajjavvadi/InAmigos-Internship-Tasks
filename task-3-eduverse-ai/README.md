# EduVerse AI - Modern EdTech Platform

EduVerse AI is a flagship education platform built during my Java/AI Web Development Internship. It features a high-fidelity glassmorphic UI and a Gemini-powered AI Study Assistant.

## 🚀 Experience the Platform
- **Intelligent Tutoring**: A real-time AI assistant for answering questions and explaining concepts.
- **AI Roadmaps**: Structured, vertical learning timelines generated by AI.
- **Bento-Grid Programs**: A curated catalog of trending career-defining courses.
- **Beast UI Design**: A premium, glassmorphic design system built for speed and impact.

## 🛠️ Technological Architecture
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS 4 + ShadCN UI
- **AI Brain**: Google Gemini 1.5
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure API Key**:
   Ensure your Gemini API key is present in `.env.local`:
   ```env
   NEXT_PUBLIC_GEMINI_API_KEY=your_api_key_here
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to see your EduVerse!
